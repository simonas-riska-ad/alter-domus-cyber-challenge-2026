2. A simple way to approach every challenge

When a challenge looks unfamiliar, do not start by trying random tools. Break the problem down.

Read the goal

What exactly are you being asked to identify: an IP, a code, a city, a filename, a domain, or a full ADCTF{...} flag?

Inspect what you have

Look at the file extension, visible text, sheet names, timestamps, URLs, headers, image clues, protocols or other obvious structure.

Search the concept

Search for the thing you do not understand — not necessarily the answer. Example: how to inspect EXIF metadata.

Try one small step

Decode the string. Open the file. Compare the two columns. Filter the packets. View the source. Confirm whether your idea makes sense.

Use a hint

Hints exist for a reason. Spending a few points is better than being stuck for an hour and learning nothing.

Then ask for help

AI, documentation and search are allowed. Try to ask for the next step or an explanation before asking directly for the final answer.

3. What to do when you are stuck

Work down this list. You usually do not need all of it.

  1. Read the challenge again. Pay attention to the exact requested output and flag format.
  2. Look at everything that is immediately visible. Filenames, extensions, timestamps, sheet tabs, URLs, HTTP fields, log levels, signs in images.
  3. Ask: what kind of data is this? Text? Image? Spreadsheet? Email? Packet capture? Binary? Encoded string?
  4. Search one specific question. “How do I view email headers?” is more useful than “how do I hack this challenge?”
  5. Try the first hint. Hint titles are intentionally vague; the paid text points you toward the concept without simply giving the answer.
  6. Use AI as a tutor. Show it what you tried and ask what you should inspect next.
  7. Walk away for five minutes. Returning with fresh eyes genuinely helps.

5. File tricks worth knowing

These ideas come up often in beginner CTFs. You do not need to memorize them — just remember that they exist so you know what to search for.

Show real file extensions in Windows

Windows may hide extensions such as .zip, .jpg or .xlsx. In File Explorer use:

View → Show → File name extensions

Once extensions are visible, you can rename a file normally with F2 or Right-click → Rename.

Renaming does not convert a file. It is useful only when you have already discovered that the file's real format is different from its current extension.

Do not blindly trust the filename

A file called report.pdf is not necessarily a PDF. File formats usually have recognizable structures or starting bytes, often called file signatures or magic bytes.

Try the Filestash file-type identifier or inspect the beginning of the file with HexEd.it / Format-Hex.

Readable strings can hide inside binary files

An application cache, executable or unknown .bin file may look unreadable when opened normally but still contain printable text.

Try a strings extractor and look for unusual URLs, filenames, usernames, error messages, configuration values or other human-readable fragments.

Office files can be archives

Modern Office formats such as .xlsx, .docx and .pptx are ZIP-based packages containing XML and other files.

For a challenge artifact, make a copy first, then you can try changing the copy's extension to .zip or opening it with an archive tool to inspect its internal structure.

A spreadsheet can therefore contain more than the cells you immediately see: worksheets, relationships, properties, comments and other internal data may all exist inside the package.

Hexadecimal is another way to represent bytes

Hex uses the characters 0-9 and A-F. One byte is commonly shown as two hex characters, from 00 to FF.

Sometimes hex represents readable text. For example:

41 44 43 54 46 → ADCTF

CyberChef can convert between hexadecimal and text quickly.

DNS names can carry data

DNS queries are normally used to resolve names, but the labels before a domain can also contain arbitrary text.

123.example.test
456.example.test

If many unusual queries share the same parent domain, the changing left-hand parts may form chunks that can be combined in timestamp order. Attackers can abuse this idea to move data through DNS.

Not every unusual subdomain is malicious — look for patterns and context.

Email: From and Reply-To are not the same thing

The visible From address tells you who the message claims to be from. A separate Reply-To header can tell your mail client to send replies somewhere else.

A different Reply-To can be legitimate, but an unexpected mismatch is worth investigating — especially in requests involving payments, credentials or urgent changes.

When inspecting an .eml file, also look at Received headers and authentication results such as SPF, DKIM and DMARC.

Keep the original evidence

Before renaming, repairing or modifying a challenge file, make a copy. That way you can always return to the original if your experiment does not work.

Copy-Item .\evidence.bin .\evidence-working-copy.bin

6. PowerShell basics for Windows

You do not need to be a command-line user. PowerShell is already available on standard modern Windows systems and can be very useful for simple CTF tasks.

How to open it: click the Windows Start/Search box, type PowerShell, then open Windows PowerShell (or open Windows Terminal and choose a PowerShell tab). You normally do not need “Run as administrator” for these challenges.

Move to your Downloads folder

Set-Location "$HOME\Downloads"

Short version:

cd "$HOME\Downloads"

List files

Get-ChildItem

Include hidden items:

Get-ChildItem -Force

Read a text file

Get-Content .\notes.txt

Search it for a word or pattern:

Select-String -Path .\notes.txt -Pattern "review"

Search several files

Get-ChildItem -File | Select-String -Pattern "ADCTF"

Useful in folders containing multiple text-based artifacts.

Decode Base64

$value = "QURDVEZ7ZXhhbXBsZX0="
[Text.Encoding]::UTF8.GetString(
  [Convert]::FromBase64String($value)
)

Look at a file in hexadecimal

Format-Hex -Path .\evidence.bin | Select-Object -First 20

The first few bytes can tell you what type of file something really is.

Extract a ZIP archive

Expand-Archive .\evidence.zip -DestinationPath .\evidence

Calculate a SHA-256 hash

Get-FileHash .\evidence.bin -Algorithm SHA256

A hash is a fingerprint for a file. It is useful for checking whether two copies are identical.

PowerShell help is built in. If you see a command you do not understand, try Get-Help CommandName -Examples. For example: Get-Help Select-String -Examples.

8. Using AI during the challenge

AI tools are not prohibited in this event. They can be excellent learning partners — but they can also remove the challenge completely if you ask for the final answer immediately.

Good ways to use AI

Explain Base64 to me and show me how I would recognize it, but do not solve my challenge.
I have a PCAP file and I am a beginner. What should I inspect first?
Here are five log lines. Explain what each field means and what patterns an analyst would look for.
Give me one hint for what I should try next, but do not reveal the flag.
Explain what this PowerShell command does line by line.

Keep this in mind

If you paste the full challenge, all artifacts and the exact question into an AI assistant and say “solve this”, it may find the answer very quickly.

That is allowed — but it can turn a 20-minute learning experience into a 20-second copy/paste exercise.

A useful compromise: try the challenge yourself first, use a hint when needed, and use AI to explain concepts or suggest the next step.

Company-data rule still applies. Only share the synthetic challenge material provided for this event. Do not paste real company emails, logs, credentials, client information, internal documents or other confidential data into external AI tools.

9. Stay inside the challenge

This is a learning environment. The scope is intentionally narrow.

OK

Inspect the files, pages, domains and challenge systems explicitly supplied in a task.

Search the public web, read documentation, use the provided hints and analyze synthetic challenge data.

Not OK

Do not scan, probe, exploit or test real Alter Domus websites, endpoints, cloud resources, employee accounts or other company infrastructure.

Do not upload real company data to public analysis websites just because a challenge taught you how to use one.

The goal is not to know everything.

The useful cybersecurity skill is knowing how to turn “I have no idea what this is” into “I know what to inspect or search for next.” Try things, research unfamiliar concepts, use the hints, and keep going.
